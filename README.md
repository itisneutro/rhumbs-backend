# Румбы ветра — расчёт времени полёта Boeing-737 NG

Учебный проект по курсу «Разработка Интернет Приложений», МГТУ им. Н.Э. Баумана, ИУ5-52Б.

**Вариант 2.** Время полёта Boeing-737 NG между Лондоном и Парижем в зависимости от направления ветра.
Услуги — 8 румбов ветра, заявка — расчёт времени с указанием отрезков маршрута.

## Стек

NestJS + TypeScript + Handlebars + Minio, всё по методичке курса.

## Лабораторная 1

Три страницы, собираемые на сервере: лента, добавление, плитка карточек.
Коллекция из 8 румбов в оперативной памяти, без базы данных.
Изображения и видео хранятся в Minio, в модели лежат только ключи.
JavaScript на страницах не используется.

Маршруты:

- `GET /rhumbs` — плитка, фильтр по параметру `minWindSpeed`
- `GET /rhumbs/feed/:id` — лента, параметр `next=true` открывает следующий румб
- `GET /rhumbs/draft` — единственный румб в статусе черновика

## Запуск

```bash
npm install
docker compose up -d
npm run start:dev
```

Приложение — http://localhost:3000/rhumbs
Консоль Minio — http://localhost:9001

## Ветки

Под каждую лабораторную своя ветка: `wind-rhumbs-catalog-lab1`, далее по спринтам.
